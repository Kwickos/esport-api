# Security Policy

## Supported Versions

Only the latest version of the `main` branch is maintained for now
(the project is in an early phase).

## Reporting a Vulnerability

**Please do NOT open a public issue** for a security flaw.

Instead, use **GitHub Security Advisories** (private reporting):

1. Go to the **"Security"** tab of the repository.
2. Click **"Report a vulnerability"**.
3. Describe the flaw, the reproduction steps, and the potential impact.

We will do our best to **respond within 7 days** and keep you informed about the
fix. Once a patch is published, we will gladly credit the person who reported the
issue (unless you prefer to remain anonymous).

## Scope

Reminder: this project consumes **unofficial endpoints** (see
[DISCLAIMER.md](DISCLAIMER.md)). Problems related to the availability or changes
of these third-party endpoints are not security flaws — please open a regular
issue for those.
