# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its Code of
Conduct. The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## In short

We are committed to a welcoming, inclusive, and harassment-free experience for
everyone. Be respectful and constructive. Abusive or disruptive behavior is not
tolerated in any project space (repository, issues, pull requests, discussions).

## Reporting

To report unacceptable behavior, please contact the maintainers **privately**:

- Open a private **GitHub Security Advisory** on the repository, or
- Contact the maintainer [@Kwickos](https://github.com/Kwickos) via GitHub.

Reports are reviewed promptly and handled confidentially.
